How to Run 100% Offline (No Internet Required)

This website has zero external dependencies (no CDN links, no external fonts, no cloud scripts). Everything runs locally on your machine between index.html, app.py, and DIP.py.

Step 1: Keep all files in the same folder 
your_folder/
 ├── index.html        (This offline web interface)
 ├── app.py            (Local Flask server linking HTML <-> DIP.py)
 ├── DIP.py            (Your OpenCV + YOLOv8 vehicle detection code)
 ├── yolov8m.pt        (Street-view model weights)
 └── yolov8m-obb.pt    (Aerial OBB model weights)
Step 2: Start the local Python server 
python app.py
Step 3: Open the Website

Either open http://127.0.0.1:5000 in your browser, or simply double-click index.html directly!
